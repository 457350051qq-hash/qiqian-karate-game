# 七千武道

一个无需安装第三方依赖的 2D Canvas 空手道小游戏。人物固定站在道场中央，八方病菌来袭，选择方向并掌握时机击破它们。

## 在 Mac 上试玩

1. 将本仓库完整下载到电脑并解压，保留文件的相对位置。
2. 用 Chrome 打开 `index.html`（可直接将文件拖入浏览器）。无需安装 Node.js、注册账号或联网。
3. 选择男性或女性武者，点击「进入道场」。
4. 用方向键选择方向，同时按两个方向键可选择斜向；按空格键攻击。每次出招需要重新按一下空格。
5. 病菌进入金色圆环时，朝它攻击。太早、太晚或方向错误不会击中。摇杆松开后保留最后朝向。

击碎 **20** 个病菌通关；病菌靠近人物算漏掉，累计 **3** 个结束。可随时点击「重新开始」重置当前角色的挑战；刷新页面可重新选择角色。声音可通过右上角按钮关闭，首次点击开始后启用。

## 手机试玩

使用本地 HTTP 服务打开页面，以获得稳定的手机浏览器体验。左手拖动八方向虚拟摇杆，右手点击「击」。支持双指同时操作，松开摇杆会保留方向。竖屏和横屏均可使用；窄屏下必要时向下滚动查看操作区。

如果 Mac 已安装 Python 3，在终端进入项目文件夹后执行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

电脑 Chrome 打开 `http://localhost:8000`。手机连接同一可信 Wi-Fi 后，在浏览器输入 `http://你的Mac局域网IP:8000`，可能需要在 Mac 防火墙中允许 Python 的本地连接。服务仅供本地试玩；终端按 Control+C 停止。无需部署公开网站或购买服务。

## 操作与规则

- 金色圆环为有效攻击区域，角色周围扇形表示当前攻击方向。
- 八个方向切换正拳、逆突、上段突、下段防守反击和踢击等占位动作，灵感来自和道流拳脚；并非正式教学示范。
- 每次攻击间隔约 0.26 秒，不能靠长按空格连续出招。
- 病菌逐渐加快，生成间隔逐渐缩短。可一击击破同方向有效范围内的多个病菌。
- 切换标签页或窗口失去焦点时暂停，返回后继续，避免后台漏怪。
- 第一版使用 Canvas 简单图形、白色道服角色和程序合成音效，无外部美术、字体或音频下载。

## 文件

- `index.html`：角色选择、画布、计分与触控界面。
- `style.css`：桌面和手机适配。
- `game.js`：游戏循环、绘制、八方向输入、攻击判定、音效与胜负逻辑。
- `tests/core.test.js`：八方向映射及攻击区域边界测试。

## 开发与验证

页面本身无需构建。若已安装 Node.js 18 或更新版本，可运行：

```sh
node --check game.js
node --test tests/core.test.js
```

开发时推荐使用上述 Python 静态服务。修改文件后刷新浏览器即可。

本版本在云环境 Chromium 中验证了加载、女性角色选择、实际键盘命中计分、斜向输入、重开、390px 手机布局、双指触控、漏掉三次结束及击碎二十个通关流程。Mac Chrome 与手机实机的画面、触感和音量仍建议在实际设备上试玩确认。

可选浏览器集成测试（需要 Node.js 22+ 和 Chromium）：先启动端口 8000 的静态服务，再在单独的终端用临时用户目录启动 Chromium：

```sh
chromium --headless --disable-gpu --remote-debugging-port=9222 --user-data-dir=/tmp/qiqian-browser-test about:blank
node tests/browser-smoke.mjs
```

Mac 可将 `chromium` 替换为 `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`。使用单独的测试浏览器，不要连接存有个人数据的日常浏览器。集成测试约需一分钟，会固定病菌来向来验证实际计分、失败和通关，也检查手机触控及浏览器异常。测试结束后关闭测试浏览器和静态服务。

## V0.2 手机操作升级

- 左侧为 360 度自由摇杆：白色圆点可连续移动，到边缘后限制在外圈内；按角度映射到原有八个攻击方向。松手、触控取消、页面失焦或旋转屏幕后圆点回中，攻击朝向仍保留。
- 右手按独立「击」按钮，可与左手摇杆双指同时操作。
- 新增「跳」按钮，电脑也可按 **J**。动画包含蓄力起跳、腾空和落地缓冲；空中不能再次起跳。跳跃仅为本次实验动作，不提供无敌、不躲避漏怪，也不改变原有攻击范围、敌人生成或胜负规则。
- 手机横屏时，摇杆与动作键放在画布左右的独立区域，避免盖住战斗画面，并适配 iPhone 刘海安全区。竖屏保持下方操作区。

### iPhone Safari 摇晃跳跃（实验）

点击「开启摇晃跳跃（实验）」后，Safari 如弹出运动与方向权限提示，请选择允许。不会自动请求权限；拒绝后仍可使用屏幕「跳」或键盘 J。可再次点击按钮关闭监听。

需要 **HTTPS 安全上下文**、可用的运动传感器及浏览器允许的权限。通过普通 `http://局域网IP:8000` 在 iPhone 上访问时，摇晃功能通常不可用，屏幕按钮和摇杆仍可试玩。直接打开本地文件也不能保证运动权限可用。本项目不部署公开网站；传感器实机测试需自行使用设备信任的本地 HTTPS 环境。

力度阈值默认 **16 m/s²**，可在页面调整到 **8–30 m/s²**；数值越小越灵敏。传感器触发冷却为 **1.2 秒**，防止一次摇晃连续起跳。优先读取不含重力的加速度；仅提供含重力读数时，使用相邻读数的变化量过滤静止重力。无有效读数时会显示提示。无需猛烈摇晃，请握稳手机轻试，并优先使用备用跳跃键。

V0.2 新增自动测试覆盖摇杆连续位移与圆形限位、八区域映射、跳跃阶段、摇晃阈值/冷却及重力回退。浏览器集成测试中的传感器与 iOS 权限接口使用模拟数据；不代表已在真实 iPhone Safari 上验证，仍需实机确认授权弹窗、传感器灵敏度及横屏体验。
